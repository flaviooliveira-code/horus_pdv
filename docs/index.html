Clone, suba o SQL Server e rode local.

Banco via Docker, API .NET e frontend Vite com variáveis de ambiente por endpoint. Simples de iniciar e fácil de auditar.

Como contribuir
zsh 
# clone
$ git clone https://github.com/flaviooliveira-code/horus_pdv.git
$ cd horus_pdv

# banco
$ docker start sqlserver2025

# api
$ cd API/NETCORE
$ dotnet run --urls http://localhost:5260

# frontend
$ cd ../../FRONTEND
$ npm install
$ npm run dev

Um fluxo simples para colaborar.

Antes de abrir PR, rode o smoke test para validar cadastro, login, navegação, CRUDs, caixa e venda.

  1. Fork

    Crie um fork do repositório e uma branch focada na mudança.

  2. Instale

    Suba SQL Server, API .NET e frontend React localmente.

  3. Teste

    Execute npm run smoke no frontend antes de enviar.

  4. Pull request

    Abra o PR com resumo, prints e escopo bem definido.

Perguntas frequentes

O Hórus PDV é grátis mesmo?

Sim. O código está sob licença MIT: você pode usar, estudar, modificar e usar comercialmente, sem mensalidade.

Serve para mercadinho, loja ou padaria?

Foi pensado para comércio de balcão: frente de caixa, cadastro de produtos, clientes e fornecedores, controle de estoque, abertura e fechamento de caixa e relatórios de vendas.

Emite NFC-e ou NF-e?

Ainda não. A camada fiscal (NFC-e / NF-e) está em desenvolvimento e aparece no roadmap.

O que preciso para instalar?

SQL Server (via Docker), .NET 8 e Node.js. Os comandos estão na seção Instalação. Um instalador para simplificar o uso em lojas está planejado.
